# 功能檢查與修復紀錄（2026-09-08）

本次檢查涵蓋桌面操作狀態、設定保存、路線管理、通知佇列、月份流程、裝置控制與匯入，並執行全部現有 Python 測試及前端測試。保留檢查前已存在的自訂路線顯示修改。

## 修復項目

| 功能 | 問題與修正 |
| --- | --- |
| 自訂路線刪除 | 改用頁內確認，避免原生確認視窗干擾焦點；成功後立即移除清單項目並解除編輯鎖定，可直接選取另一條路線。 |
| 路線保存、匯入、載入 | 保存與匯入成功後直接使用 API 結果，不因後續清單讀取失敗誤報操作失敗；載入失敗保留原本選取及編輯內容。操作進行中鎖住編輯器，避免不同操作互相覆蓋。 |
| 執行中的來源路線 | 後端拒絕整條刪除或覆寫正在使用的來源路線；既有「刪除目前節點並前往下一節點」流程仍可使用。 |
| Discord 通知 | 每一批實際發送前讀取最新保存設定。待送通知跟隨新的 Webhook、Bot Token／頻道；停用時略過尚未發送的批次。已送出的請求無法撤回。 |
| 共用設定 | 前端只提交本次修改的區塊，後端以鎖定的讀取／合併／保存操作更新；避免篩選條件、模型與播報網址互相覆蓋。保留原有 PUT API，新增並允許 Electron／本機網頁使用 PATCH。 |
| 即時設定同步 | 收到設定更新與連線恢復通知後重新讀取；較早開始的設定或模型讀取不再覆蓋較新的回應。 |
| 工作狀態 | 加入遞增版本，拒絕過期工作更新與已完成工作重新變成執行中。WebSocket 重連後重新同步工作，解除遺留的按鈕鎖定。 |
| 月份流程 | 舊月份的延遲回應不再覆蓋新月份；載入期間停用資料操作；上傳、刪除、審核與啟動期間避免交錯提交。批次上傳部分成功時保留已成功的顯示。 |
| 手機端設定同步 | 依實際設定內容判斷變更，同一台手機的設定修改或備份還原可反映至桌面；設定未變的輪詢不會清掉桌面草稿。 |
| 座標與路線匯入 | 拒絕空白、null、布林等無效座標；GPX 支援不同經緯度屬性順序、空格與命名空間；裝置路線可匯入 BloomPilot 座標序列 JSON。 |
| API 等待 | 加入回應期限，逾時不反覆重送；保留啟動時的網路重試等待，寫入操作不自動重試。 |
| 首次安裝入口 | 將啟動器中不存在的 01_安裝環境.bat 引用修正為實際的安裝環境.bat。 |
